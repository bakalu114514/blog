我的第一篇博客（随手一记）

约 519 字大约 2 分钟

2025-12-15

前言

这是我的第一篇博客，算是一次随手记录，也作为博客的起点。

在此之前，我已经通过 Vue 项目的创建教程，学会了基本的 Vue 项目初始化流程。今天在此基础上，成功搭建并部署了自己的博客。

博客搭建过程

本次博客使用的是 VuePress，并选择了 Plume 主题（感谢作者 pengzhanbo）。
整体流程和创建普通 Vue 项目类似，上手难度不算高，配置也相对清晰。

遇到的问题与踩坑记录

真正花时间的地方主要集中在 GitHub Pages 的部署 上。

1. 部署方式更新

之前查到的一些部署方法已经被替代，现在有了更加简化的流程。但需要注意的是：

  • 在 commit 时一定要填写提交信息
  • 如果忘记命名 commit，虽然不影响功能，但会浪费不少排查时间

2. base 配置导致 CSS 不生效

在提交并部署完成后，还需要重点检查：

  • deploy.yml 中的 base 是否设置正确
  • 如果 base 配置错误，页面会正常打开，但 CSS 无法加载

此时可以：

  • 在网页中按 F12 打开开发者工具
  • 查看控制台报错，通常会看到 404（资源未找到） 的错误信息

3. GitHub Pages 部署延迟

还有一个容易让人误判的问题：

  • GitHub 显示 Actions 运行成功
  • 但页面样式依然不生效

这种情况不一定是配置错误，而是 GitHub Pages 的缓存与同步存在延迟。
解决方法很简单：等待 3～5 分钟即可。

结语

总体来说，这是一次还算顺利但也踩了不少小坑的经历。
通过这次博客的搭建，对 VuePress、GitHub Pages 部署流程以及常见问题都有了更直观的认识。

希望之后能持续记录学习过程，把这个博客真正用起来。
